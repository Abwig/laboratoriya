# Лаборатория

Учебная браузерная игра по физике для 10 класса: насыщенный и ненасыщенный пар.
Пять интерактивных опытов в 2D-лаборатории, в каждом по три задания и оценка до трёх звёзд.

1. Динамическое равновесие — испарение и конденсация в стакане.
2. Сжатие пара поршнем — график p(V), момент насыщения.
3. Давление пара и температура — снятие кривой p₀(t), сравнение с законом Шарля.
4. Кипение под колоколом — кипение воды при 60 °C при пониженном давлении.
5. Влажность и точка росы — запотевание стакана, расчёт относительной влажности.

## Запуск

Откройте сайт на GitHub Pages или локально:

```
python -m http.server 8765
```

и перейдите на http://localhost:8765.

Чистые HTML, CSS и JavaScript, без сборки и зависимостей.
